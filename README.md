# M7 Bike & Scooters Website

A professional responsive website for **M7 Bike & Scooters**, a bicycle and scooter shop offering sales, repairs, accessories, spare parts, used bike buying and selling, bike rentals, and service centre support.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Responsive component-based UI

## Pages

- Home
- About
- Services
- Buy & Sell Bikes
- Bike Rental
- Repairs
- Contact

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

Build for production:

```bash
npm run build
```

## Customisation

- Update business text and phone links in `components/site-data.ts`.
- Replace gallery placeholders in `components/Gallery.tsx` or add real shop images in `public/gallery`.
- Connect the contact form in `components/ContactBlock.tsx` to an email, CRM, or API endpoint.
- Replace the map placeholder with a Google Maps embed for the shop location.
